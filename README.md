# 🤖 Nazama Bot

Nazama Bot adalah bot multifungsi yang dirancang untuk otomatisasi, manajemen server, dan interaksi cerdas.

---

## ✨ Fitur Utama

- ⚡ **Cepat & Responsif**: Performa optimal dengan latensi rendah.
- 🛡️ **Moderasi Otomatis**: Menjaga komunitas tetap aman dari spam dan konten terlarang.
- 🎵 **Entertainment & Utilitas**: Fitur interaktif, mini-game, dan utilitas harian.
- 🌐 **Web Dashboard**: Pantau status dan konfigurasi bot secara langsung melalui web interface.

---

## 📋 Prasyarat

Sebelum memulai, pastikan perangkat Anda telah terpasang:

- [Node.js](https://nodejs.org/) (versi 18.x atau lebih baru)
- [Git](https://git-scm.com/)
- Package manager: `npm`, `yarn`, atau `pnpm`

---

## 🚀 Panduan Instalasi

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/bacotbanget1/nazama-bot.git
   cd nazama-bot
   ```

2. **Instal dependensi:**
   ```bash
   npm install
   ```

3. **Konfigurasi Lingkungan (.env):**
   Salin file template konfigurasi dan sesuaikan isinya:
   ```bash
   cp .env.example .env
   ```

4. **Jalankan Bot:**
   ```bash
   # Mode Produksi
   npm start

   # Mode Pengembangan (Hot Reload)
   npm run dev
   ```

---

## 🌐 Web Interface

Buka `index.html` di browser favorit Anda atau gunakan local server:
```bash
npx serve .
```
Akses antarmuka melalui: `http://localhost:3000`
